# Bookstore.Api (REST API Tasarımı / REST API Design series)

Small Bookstore API used to show the contract decisions of the series with real HTTP exchanges.

Requirements: .NET 10 SDK, Node.js 24 (only for linting the contract).

```
dotnet run --project src/Bookstore.Api      # http://127.0.0.1:52318
npm ci
npm run lint:contract                       # Redocly CLI + Spectral
npm run mock                                # Prism mock of the contract on http://127.0.0.1:52328
npm run generate:client                     # TypeScript types for bookstore-web
npm run drift                               # contract vs. the document generated by the running API
```

Breaking changes: oasdiff 1.37.0 (https://github.com/oasdiff/oasdiff/releases),
`oasdiff breaking base.yaml contract/bookstore.openapi.yaml --fail-on WARN`. CI: .github/workflows/contract.yml.

- contract/bookstore.openapi.yaml: the API contract (OpenAPI 3.2), written before the code.
- docs/api-style-guide.md and docs/adr/: design rules and decisions.
- docs/api-review-checklist.md, docs/reviews/ and docs/api-catalog.md: how API changes are reviewed and the API inventory.
- src/Bookstore.Api/Legacy: the old RPC-style endpoint kept as a counterexample.
- clients/angular-snippets: the bookstore-web error interceptor (Angular 22.2, TypeScript 6.0);
  `cd clients/angular-snippets && npm ci && npm run typecheck`.

Demo authentication: `Authorization: Bearer <name>` signs in as one of the demo users
(ada, nevin, alan, linus, grace, ayse) defined in src/Bookstore.Api/Identity/DemoAuthentication.cs.

# INC-2026-11-12: institution order lists readable by another institution

Severity: SEV-2 (security). Status: closed. Times in UTC.

## Timeline

| Time | Event |
|---|---|
| 2026-11-11 14:03 | First cross-institution read in the audit log (user of institution 2 lists institution 1) |
| 2026-11-12 08:40 | Lakeside School reports that a Hillcrest user mentioned their order list |

## Root cause

The institution portal endpoint added in release 2 took the institution id from the URL and checked only the role.
The pull request did not tick the threat model box, so the new flow never reached the model.

## Actions

- Regression tests `InstitutionOrdersIncidentTests` (ASVS v5.0.0-8.4.1, v5.0.0-16.3.2).
- Threat T13 added to the model; flow 5 of the institutional diagram added.
- New endpoints under `/api/institutions/me/...` take the institution from the token only.
- Alert on audit rows where the caller's institution differs from the resource's institution.
